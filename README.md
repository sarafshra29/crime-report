🚔 Crime Data Analysis & Prediction Dashboard
📌 Project Overview

This project focuses on analyzing crime data and building an interactive dashboard along with predictive models to uncover insights and trends in criminal activities.

The goal is to:

Perform Exploratory Data Analysis (EDA)
Build interactive visual dashboards
Develop machine learning models for prediction
Provide actionable insights for decision-making
📂 Dataset
Dataset: crimes_2001_2026.csv
Contains crime records including:
Date & Time
Location
Crime Type
Arrest status
Other relevant attributes
⚙️ Features
🔍 Exploratory Data Analysis (EDA)
Crime trends over time
Most common crime types
Arrest rate analysis
Location-based crime distribution
📊 Dashboard (Streamlit)
Interactive filters (date, location, crime type)
KPI metrics:
Total Crimes
Arrest Rate
Most Frequent Crimes
Visualizations:
Line charts (trend analysis)
Bar charts (category comparison)
Maps (if implemented)
Pie charts (distribution)
🤖 Machine Learning
Predictive model for:
Crime occurrence
Arrest probability
Algorithms used:
Random Forest / XGBoost / Logistic Regression (customize)
Model evaluation:
Accuracy
Confusion Matrix
Precision & Recall
🛠️ Tech Stack
Python
Pandas, NumPy – Data Processing
Matplotlib, Seaborn, Plotly – Visualization
Scikit-learn / XGBoost – Machine Learning
Streamlit – Web Dashboard
MLflow (optional) – Model tracking
